---
title: Privacy
description: Sumi collects nothing.
---

Sumi has no account, no telemetry and no analytics. Version 0.1.0 doesn't use the network at all.

Features that need the network will stay off until you turn them on:

- **Weather** asks [Open-Meteo](https://open-meteo.com) for the forecast of the city you enter.
- **Calendar** downloads the ICS address you paste.
- **Update checks** ask GitHub for the latest version.

Notification and clipboard content will be shown, never written to a log or a file.

This site is hosted on GitHub Pages, serves its own fonts and loads no tracker. On the home page, a question asked in the command bar demo is sent to Wikipedia, and only when you submit it.
