---
title: Install
description: Download and install Sumi on Windows 10 or 11.
---

Sumi runs on Windows 10 and 11, 64-bit.

1. Download [Sumi-setup.exe](https://github.com/Rateur/sumi/releases/latest/download/Sumi-setup.exe).
2. Run it. Windows warns about an unknown publisher: select **More info**, then **Run anyway**.
3. Open Sumi from the Start menu. The island appears at the top of your main screen.

:::note[Why the warning?]
The installer isn't signed yet. Signing is free for open-source projects and comes before 1.0.
:::

## Quit

Right-click the Sumi icon in the notification area, then select **Quit Sumi**.

## Uninstall

**Settings** › **Apps** › **Installed apps** › **Sumi** › **Uninstall**.

## Requirements

- Windows 10 or 11, 64-bit.
- WebView2. It's built into Windows 11; on Windows 10, the installer adds it if it's missing.
